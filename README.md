# B7GYM — лендинг

Статический сайт спортивного клуба B7GYM (Ташкент, 800 м²).

## Структура

```
index.html      — страница целиком (разметка, стили, логика)
assets/         — изображения, шрифты, библиотеки (GSAP, ScrollTrigger, Lenis, Leaflet)
.nojekyll       — отключает обработку Jekyll на GitHub Pages
```

Внешних CDN нет: все зависимости лежат локально, сайт работает без интернета
(кроме тайлов карты OpenStreetMap в секции контактов).

## Публикация на GitHub Pages

Settings → Pages → Source: `Deploy from a branch` → Branch: `main`, папка `/ (root)`.

## Локальный запуск

```bash
python3 -m http.server 8000
```

Затем открыть http://localhost:8000

Открывать `index.html` двойным кликом (протокол `file://`) нельзя — шрифты
и скрипты не загрузятся.
